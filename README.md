# Dunjun

A 2D dungeon roguelike with optional dynamic difficulty.

Playable build: https://r3dum.itch.io/dunjun

## Controls

- **WASD** — move
- **Left mouse** — attack
- **Q** — relic inventory

## Open in Unity

1. Install Unity 6000.3.10f1 or later
2. Open this folder as a Unity project
3. Open `Assets/Scenes/SampleScene.unity` and press Play
